# 판서 정리 도우미 작업·검증 보고서

태스크: LECTURE-BOARD-20261118 / 요청자: 강석현 / 담당자·실제 수행자: Codex AI

목표: 제출 대상을 판서 정리 도우미로 바로잡고, 두 종류 이상의 입력을 실제 정리에 반영한다. 완료 기준은 사진+텍스트·사진+음성 분석, 네 칸 결과, 배포된 화면과 API, 서비스 URL·값이 가려진 Secrets·/docs 캡처 제공이다.

구현: 사진에 텍스트와 WAV 음성 질문을 함께 보낸다. 사진만 있는 요청·잘못된 파일·1분 초과 음성·전체 4백만 자 초과 입력을 모델 호출 전에 거절한다. 접근 코드가 설정되지 않으면 503으로 차단한다. 결과와 음성 질문 해석을 화면에 표시한다.

로컬 검증: Python 3.11, FastAPI 0.141.1, google-genai 2.12.1, Pillow 11.3.0. 인증·파일·최소 두 종류 입력·합산 크기·음성 길이·혼합 입력 전달·잘못된 AI 출력에 대한 모의 검사 12개 통과. 실제 외부 AI와 배포 화면 검증은 이어서 수행한다.

영향: 별도 Study 브랜치의 판서 폴더를 추가한다. 이전 사진·음성 실습은 제출 대상에서 제외한다. Vercel의 기존 프로젝트 설정을 재사용하며 기존 /describe·/listen 실습 경로는 유지한다. main 병합은 사용자 검토 전까지 하지 않는다.

예정 검증: 텍스트 질문은 base64만 설명하도록, 합성 음성 질문은 JSON 복습 질문만 만들도록 요청해 결과 반영을 확인한다. 예제는 직접 만든 판서와 합성 음성이다. 사람의 실제 휴대폰 카메라·마이크 사용은 미확인으로 구분한다.

검증 상태: 로컬 모의 검사 완료 / 실제 AI·배포·제출 캡처 진행 중 / 회의 공유 개인 작업으로 해당 없음 / 승인·머지 사용자 검토 대기. 배포 완료와 관찰한 결과는 이 문서를 갱신해 남긴다.
