목표: 제출 대상을 판서 정리 도우미로 바로잡고, 두 종류 이상의 입력을 실제 정리에 반영한다. 완료 기준은 사진+텍스트·사진+음성 분석, 네 칸 결과, 배포된 화면과 API, 서비스 URL·값이 가려진 Secrets·/docs 캡처 제공이다.

구현: 사진에 텍스트와 WAV 음성 질문을 함께 보낸다. 사진만 있는 요청·잘못된 파일·1분 초과 음성·전체 4백만 자 초과 입력을 모델 호출 전에 거절한다. 접근 코드가 설정되지 않으면 503으로 차단한다. 결과와 음성 질문 해석을 화면에 표시한다.

로컬 검증: Python 3.11, FastAPI 0.141.1, google-genai 2.12.1, Pillow 11.3.0. 인증·파일·최소 두 종류 입력·합산 크기·음성 길이·혼합 입력 전달·잘못된 AI 출력에 대한 모의 검사 12개 통과. 실제 외부 AI와 배포 화면은 아래와 같이 따로 검증했다.

영향: 별도 Study 브랜치의 판서 폴더를 추가한다. 이전 사진·음성 실습은 제출 대상에서 제외한다. Vercel의 기존 프로젝트 설정을 재사용하며 기존 /describe·/listen 실습 경로는 유지한다. main 병합은 사용자 검토 전까지 하지 않는다.

[실측 결과](Verification_Results.json), [실행 화면](evidence/Board_Voice_Result.jpg)을 근거로 남긴다. 사람의 실제 휴대폰 카메라·마이크는 미확인이다.

제출물: 바탕화면 `20261118_AI_PLF_LectureBoard_Submission.zip`에 URL 텍스트와 [Secrets 캡처](evidence/Streamlit_Secrets_Masked.jpg), [API 문서 캡처](evidence/API_Docs.jpg)만 담았다. Secrets 값은 화면에서 임시 별표로 바꿔 검수한 뒤 캡처했고, Discard하여 실제 설정을 유지했다. 가림 적용 전 찍힌 컷은 검수에서 제외하고 같은 파일을 안전한 캡처로 교체했다. 가림 전 컷은 저장소나 제출 ZIP에 포함하지 않았다. 실제 과제 사이트 업로드는 하지 않았다.

배운 점·개선: 멀티모달 조건은 화면에 입력칸만 추가하는 것으로 끝나지 않는다. 질문 종류를 실제 모델 입력에 포함하고, 서로 다른 질문 조건이 결과를 바꾸는지 검증했다. 캡처는 가림 적용과 비밀 값 비노출을 눈으로 확인한 동일 이미지 바이트를 저장해야 한다.
